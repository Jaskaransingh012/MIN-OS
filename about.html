A desktop operating system that lives in one browser tab.

MIN-OS (JK OS) boots, opens windows, runs a shell, edits files and browses the web. Everything runs in your browser. No server, no build step, no framework.

What it is

MIN-OS is a front-end "OS in a page". It starts with a simulated kernel boot, then shows a desktop with a wallpaper, icons, a clock, a right-click menu and a vertical dock. Apps open in real windows that you can drag, resize, minimize, maximize and stack. Your files are saved in the browser, so they are still there when you come back.

Four apps

Open them from the dock or from desktop icons. You can run more than one window of the same app.

Terminal

Terminal

A shell with ls, cd, mkdir, touch, echo, cat, cp, mv, rm, clear, find and a built-in vim.

Files

File Manager

Browse, create and navigate the virtual filesystem. Documents, Desktop, Downloads, Pictures, Music and Videos exist from the first boot.

Editor

Text Editor

Edit files with line numbers, find and replace, and undo/redo. Opens and saves straight to the filesystem.

Browser

Browser

Tabs, an address bar, bookmarks and quick links. Search uses Wikipedia, with DuckDuckGo as a fallback.

How it boots

The kernel starts services in a fixed order, so each step can rely on the one before it.

  1. Boot screen. Animated logs and a progress bar appear while the system starts.
  2. Storage. IndexedDB opens (database JK_OS, store FileStorage), with a localStorage fallback.
  3. Filesystem. The saved tree is restored, default folders are created if missing, and the working directory is set to /Desktop.
  4. Shell. The command registry and shell are registered.
  5. Windows and apps. The window manager starts and the four apps are registered.
  6. Desktop. Wallpaper, icon grid, dock, clock and context menu mount, the session is restored and the boot screen fades out.

Under the hood

Small, separate modules wired together by a simple service container.

Architecture

index.html → main.js → Kernel → Bootstrapper
 ├─ ServiceContainer (dependency injection)
 ├─ WindowManager / Window / WindowFactory
 ├─ AppManager / AppRegistry / BaseApp
 ├─ FileSystem + FileRepository + PathResolver
 ├─ Shell + CommandRegistry + commands
 ├─ Clipboard
 ├─ StorageFactory → IndexedDB | localStorage
 └─ UI: Desktop, Dash, BootScreen

Run it yourself

There is no build step. Serve the folder with any static server. Opening index.html directly with file:// will not work, because browsers block ES module imports there.

npm install
npx serve .
# or
python3 -m http.server 8080

Then open http://localhost:8080.

Known limits

MIN-OS is a work in progress. These are the current rough edges.

  • Some sites will not load in the Browser app. Sites that forbid embedding show an in-app error instead.
  • Tab completion in the Terminal is not working yet.
  • Some command files are not registered yet, such as grep and tree.
  • Files live in your browser only. Clearing site data erases the filesystem.
